# Бот акции для мессенджера МАКС

Бот для проведения акции: участники регистрируются (ФИО, бонусная карта, телефон,
город), присылают фото чеков, каждый получает порядковый номер `0001`. Каждый
понедельник бот запускает розыгрыш: случайно перебирает новые чеки за неделю и
показывает их оператору **прямо в МАКС** с кнопками **«Победитель»** / **«Следующий»**.
Есть выгрузка участников в Excel.

> Основная площадка — **МАКС** (`run_max.py`). В проекте также есть адаптеры
> Telegram и ВКонтакте (`telegram_bot.py`, `vk_bot.py`) на том же общем ядре — их
> можно включить позже, но по умолчанию они не запускаются.

## Возможности

- Регистрация участника: ФИО → бонусная карта → телефон → город.
- Порядковый номер в формате `0001` (отдельная нумерация по площадке).
- Приём фото чеков (в МАКС фото скачивается локально в `data/media/`).
- Еженедельный авто-розыгрыш (понедельник) + запуск вручную командой `/draw`.
- Число победителей задаёт оператор: `/winners N` (по умолчанию из `.env`).
- Проверка чеков оператором в МАКС: бот шлёт чек с кнопками «Победитель» / «Следующий».
- **Каждый чек участвует в розыгрыше, но один человек побеждает не больше одного раза**
  (после победы остальные его чеки авто-пропускаются).
- Выгрузка в Excel **только тех, кто загрузил хотя бы один чек**: номер, ФИО,
  телефон, город, бонусная карта, площадка, дата.

## Структура

```
app/
  config.py        — чтение .env
  db.py            — SQLite + SQLAlchemy
  models.py        — Participant / Receipt / Draw / Setting
  settings.py      — число победителей (хранится в БД)
  services.py      — вся бизнес-логика (регистрация, чеки, розыгрыш) — общая для всех площадок
  export.py        — выгрузка Excel
  max_bot.py       — МАКС: регистрация, чеки, панель оператора (maxapi)
  telegram_bot.py  — Telegram (опционально)
  vk_bot.py        — ВКонтакте (опционально)
  scheduler.py     — понедельничный розыгрыш (APScheduler)
run_max.py         — ЗАПУСК: МАКС + планировщик
run_telegram.py    — опционально: Telegram + планировщик
run_vk.py          — опционально: ВКонтакте
_selftest.py       — автотест бизнес-логики (без токенов)
```

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env    # заполнить MAX_BOT_TOKEN и MAX_ADMIN_IDS
```

## Настройка `.env` (для МАКС)

- `MAX_BOT_TOKEN` — токен бота от **@MasterBot** внутри мессенджера МАКС.
- `MAX_ADMIN_IDS` — MAX user_id операторов через запятую. Узнать свой id: запустите
  бота и отправьте ему команду `/myid`.
- `MAX_ADMIN_CHAT_ID` — чат, куда слать чеки на проверку. Можно оставить пустым:
  он запомнится автоматически, когда оператор первый раз напишет боту `/admin` или `/draw`.
- `MAX_OWNER_ID` — **владелец** (супер-админ): один MAX user_id с доступом к панели
  `/panel` (редактирование текстов и рассылка). Узнать id: команда `/myid`.
- `DEFAULT_WINNERS_COUNT`, `DRAW_DAY`, `DRAW_HOUR`, `DRAW_MINUTE`, `TIMEZONE` — розыгрыш.

## Запуск

```powershell
.\.venv\Scripts\python.exe run_max.py
```
В консоли появится лог запуска — бот работает. Окно не закрывать. Остановить — `Ctrl+C`.
Для круглосуточной работы разместите на сервере (VPS) как службу/через автозапуск.

## Команды оператора (в МАКС)

| Команда        | Действие                                             |
|----------------|------------------------------------------------------|
| `/admin`       | список команд                                        |
| `/draw`        | запустить розыгрыш вручную                            |
| `/winners N`   | задать число победителей                             |
| `/export`      | Excel с участниками (у кого есть чеки)               |
| `/stats`       | статистика                                           |
| `/myid`        | показать свой MAX user_id                            |

## Панель владельца (`/panel`)

Доступна только пользователю из `MAX_OWNER_ID`. Открывается командой `/panel`,
управление — кнопками:

- **✏️ Тексты бота** — все сообщения бота, разбиты на два раздела:
  - **👤 Тексты участнику** — приветствие, запросы ФИО/карты/телефона/города,
    подтверждения, ошибки.
  - **🛠 Тексты оператору** — карточка чека, подписи кнопок «Победитель»/«Следующий»,
    уведомления, итог розыгрыша.

  Любой текст можно изменить или сбросить к стандартному. Подстановки вроде `{number}`
  (номер участника), `{count}` (принято чеков), `{full_name}`, `{city}` и т. п.
  сохраняются — панель подсказывает, какие доступны для конкретного текста.
- **🏆 Победителей: N** — изменить число победителей на розыгрыш.
- **🗓 Розыгрыш: Пн 10:00** — изменить день и время авто-розыгрыша (например, «пн 10:00»
  или «fri 18:30»). Применяется к работающему планировщику **сразу, без перезапуска**.
- **📣 Рассылка участникам** — отправить сообщение всем участникам МАКС. Бот сначала
  покажет **предпросмотр и число получателей**, и отправит только после подтверждения
  кнопкой «✅ Отправить всем».

Все изменения хранятся в БД и применяются сразу, без перезапуска бота.

## Как идёт розыгрыш

1. В понедельник (или по `/draw`) бот берёт все **новые** чеки (ещё не участвовавшие
   в розыгрышах), перемешивает их и присылает первый чек оператору.
2. Оператор смотрит фото: если нужный товар на нужную сумму есть — **«Победитель»**,
   иначе — **«Следующий»**.
   - При нажатии «Победитель» участнику **автоматически приходит уведомление**
     (текст редактируется в панели → Тексты участнику → «Уведомление победителю»).
     Если доставить не удалось (например, участник закрыл диалог с ботом), оператор
     получает предупреждение и может связаться вручную.
3. Так до тех пор, пока не наберётся заданное число победителей или не кончатся чеки.
4. Как только человек победил, остальные его чеки в этом розыгрыше пропускаются
   автоматически — дважды один участник не выигрывает.
5. Каждый показанный чек в следующий розыгрыш уже не попадает.

## Автотест

```powershell
.\.venv\Scripts\python.exe _selftest.py
```
Проверяет регистрацию, нумерацию, приём чеков, розыгрыш (в т.ч. «одна победа на человека»),
фильтр Excel и защиту от повторного клика — без реальных токенов.

## Важные заметки

- **Публикация ботов в МАКС.** По актуальным правилам МАКС публиковать ботов и
  мини-приложения можно только через верифицированное юрлицо РФ — уточните это под
  свою ситуацию (возможно, потребуется участие компании-организатора).
- **API/библиотека.** Используется [`maxapi`](https://pypi.org/project/maxapi/)
  (стиль aiogram). Официальная документация MAX Bot API — [dev.max.ru](https://dev.max.ru/docs-api).
- **Хранилище** — SQLite (`data/bot.db`), фото чеков — в `data/media/`. Для больших
  объёмов можно перейти на PostgreSQL, поменяв строку подключения в `app/db.py`.
- Всё «живое» тестирование МАКС требует реального токена от @MasterBot; логика ядра
  и сборка бота проверены автотестом и smoke-тестом.
